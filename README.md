# Complete Study Guide for Placement Interviews

A curated collection of self-contained Markdown study guides and cheat sheets covering the core CS subjects, System Design, and Data Science topics most commonly tested in campus placement and SDE interviews.

Each subject typically comes as a pair:
- **Study Guide** — in-depth explanation of every concept with reasoning, examples, and interview framing (learn it once, don't need to re-read).
- **Placement Cheat Sheet** — dense, quick-recall reference for last-minute revision.

### System Design (34-Day Plan)

A structured, ~1 hour/day curriculum in [`System Design/`](System%20Design), broken into five phases:

1. **Foundational Concepts** (Days 1–16) — scalability, load balancing, caching, SQL vs NoSQL, API design, rate limiting, CAP theorem, microservices, sharding, and more.
2. **High-Level Design (HLD)** (Days 17–22) — URL shortener, rate limiter, pastebin, chat system, notification system, e-commerce order flow, social feed, file storage.
3. **Low-Level Design (LLD) / OOD** (Days 23–32, C++) — OOP fundamentals, SOLID principles, design patterns, UML, and LLD problems (parking lot, elevator, library system, vending machine, ATM, tic-tac-toe/snake-ladder/chess, movie booking).
4. **Company-Specific Strategy** (Day 33) — how to navigate different interview round formats.
5. **Buffer / Revision / Mock Practice** (Day 34) — full revision pass and timed mock assessments.

See [`System Design/README.md`](System%20Design/README.md) for the full day-by-day breakdown.

## How to Use

- New to a topic → start with the **Study Guide**.
- Reviewing before an interview → use the **Cheat Sheet**.
- Prepping for system design rounds → follow the 34-day plan in order; each day builds on the last.
