# System Design Preparation Planner (34-Day Plan)

## Overview
This repository contains a comprehensive system design preparation planner aimed at beginners and freshers [cite: 1]. The primary goal is to achieve readiness for job interviews and online assessments with a strict daily time budget of 1 hour/day [cite: 1]. 

## Curriculum Structure
The preparation is organized into 5 distinct phases [cite: 1]:

### Phase 1: Foundational Concepts (Days 1-16)
*   **Focus:** Core system design principles [cite: 1].
*   **Key Topics:** Scalability, Load Balancing, Caching, SQL vs NoSQL, API Design, Rate Limiting, CAP Theorem, Microservices, and Database Sharding [cite: 1].
*   **Goal:** By the end of Day 16, you should be able to explain all 23 foundational concepts out loud in 2-3 sentences each without notes [cite: 1].

### Phase 2: High-Level Design (HLD) (Days 17-22)
*   **Focus:** Practical "Design X" prompts [cite: 1].
*   **Key Topics:** Design a URL Shortener, Rate Limiter, Pastebin, Chat System, and E-commerce Order Flow [cite: 1].
*   **Goal:** By the end of Day 22, you should be able to sketch a basic component diagram for any of the 8 systems in under 10 minutes [cite: 1].

### Phase 3: Low-Level Design (LLD) / OOD (Days 23-31)
*   **Focus:** Object-Oriented Design and coding [cite: 1].
*   **Key Topics:** OOP Fundamentals, SOLID Principles, Design Patterns, and LLD prompts like a Parking Lot and Elevator system [cite: 1].
*   **Goal:** By the end of Day 31, you should be able to take any of the 14 LLD prompts cold and produce a class list with relationships within 15 minutes [cite: 1].

### Phase 4: Company-Specific Strategy (Day 32)
*   **Focus:** Navigating different interview formats [cite: 1].
*   **Key Topics:** Strategies for OOP+DBMS+SQL rounds, LLD/Machine Coding, HLD, and scenario-based MCQs [cite: 1].

### Phase 5: Buffer / Revision / Mock Practice (Days 33-34)
*   **Focus:** Retention and stress-testing [cite: 1].
*   **Key Topics:** Full revision pass of Phase 1 flashcards, redoing HLD designs from memory, and timed mock assessments (MCQs + cold-designing an LLD problem) [cite: 1].

## Summary
*   **Total topics covered:** 49/49 (100% coverage) [cite: 1].
*   **Total study days:** 32 [cite: 1].
*   **Buffer/revision days:** 2 [cite: 1].
*   **Daily commitment:** Strictly 1 hour/day throughout the entire process [cite: 1].
